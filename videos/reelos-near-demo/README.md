# ReelOS NEAR working demo

54-second evidence walkthrough plus an 20-second freshly rendered sample.
Run `npm run check`, `npm run dev`, and `npm run render` in this folder.
Private assets/renders are ignored. They are staged from the existing supplied
footage and captured real local editor screens. See BRIEF.md, SPEC.md and REVIEW.md.

The walkthrough does not claim fresh AI inference or a completed payment. It shows
a fresh local render using the saved plan and cached masks, actual editor playback,
and the deployed public testnet escrow. Wallet funding/delivery/approval are pending.

Final local outputs: `data/near-demo/reelos-test-footage-broll-v2-1080p.mp4`
(20s vertical edit) and `data/near-demo/reelos-near-working-demo-v2.mp4` (54s
landscape walkthrough), relative to the repository root. The latter also lives
in this project's ignored `renders/` folder. The live editable preview is
http://127.0.0.1:3121/#project/reelos-near-demo.
