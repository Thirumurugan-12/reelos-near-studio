# Showcase provenance

The presentation is assembled with HyperFrames 0.8.220. Its installed package metadata declares Apache-2.0; the scaffold and project instructions were generated by that CLI. See the [upstream project](https://github.com/heygen-com/hyperframes) and installed package metadata. No HyperFrames runtime is copied into the ReelOS production service.

GSAP 3.14.2 is the declared presentation animation runtime; its source retains its own notices and is governed by the [GSAP licence](https://gsap.com/standard-license/). Inter is the presentation font; see the [font author's licence](https://github.com/rsms/inter/blob/master/LICENSE.txt). These dependencies are separate from the app's Remotion illustration runtime.

All speaker footage, actual app captures, SAM thumbnails and real rendered edit/revision clips follow the repository's existing source permissions and [media provenance record](../docs/DEPENDENCIES.md). The two stock evaluation clips have their original authors and source pages in [the evaluation asset record](../docs/EVALUATION_ASSETS.md). They are technical examples, not endorsements.

The original instrumental score is generated from the first-party `compose_audio.py` source, without third-party samples or paid model calls. An external music candidate was investigated but could not be downloaded and is not used. No generated avatar, cloned voice or copied reference screenshots appear in the showcase.

Private media, derived thumbnails, waveform data, renderer history/cache and MP4s remain excluded from Git and the app Docker build context. The asset ledger contains source descriptions and hashes, not media payloads or API credentials.
